# 職業・特技・魔法の再設計案

## 診断

現状は15職×4段階で60個の習得枠があるが、報酬になっている技IDは37個だけで、
23枠は別職との重複になっている。共有そのものより、共有された技の多くが
威力・MP・対象範囲・行動コストだけの差であることが問題。

- `つらぬき` は防御無視用の引数が実行経路から渡されず、普通の単体物理攻撃。
- `ときとまれ` は敵全体への通常の鈍足、`ひっさつ` は条件なしの高威力攻撃。
- `けむりだま` は敵全体への鈍足で、`あそぶ` と `きまぐれ` は同じ効果表を使う。
- 炎・氷・雷は主に弱点倍率と対象範囲の違いで、属性ごとの戦い方がない。
- 習得済みの全技を常時使えるため、転職を重ねるほど現職より過去職の強技が目立つ。
- オートは攻撃をほぼ「威力×回数÷行動コスト」で選び、妨害や副次目的を評価しない。

## 参考作品から借りる構造

### FF5から借りるもの

公式説明では、ジョブレベルで能力を習得し、それらを組み替えることで
独自の構成を作る点が中心に置かれている。ここから「現職の個性を土台にして、
過去職から選んだ一部だけを足す」という構造を借りる。

- 現職だけで最低限の役割が成立する。
- 過去職の習得物は失わないが、戦闘へ持ち込むものは選ぶ。
- 強さより、異なる役割同士の組み合わせが報酬になる。

参考:
[FF5公式](https://www.jp.square-enix.com/game/detail/ff5/) /
[FF5アドバンス公式](https://www.jp.square-enix.com/archive/ff5a/)

### DQ6から借りるもの

公式説明では、職業ごとの熟練で特技・呪文を覚え、転職後も保持すること、
基本職のマスターから上位職が開くことが示されている。ここから「寄り道も将来の
進路になる長期育成」と「職業を極める明確な目的」を借りる。

- 熟練はランをまたいで残り、途中で転職しても無駄にならない。
- 複数職の節目が上位職への経路になる。
- 各職は固有の技と役割を持ち、進路を選ぶ情報を事前に見せる。

参考:
[DQ6公式](https://www.jp.square-enix.com/dqsp/dq6/system/) /
[Nintendo公式の職業解説](https://www.nintendo.com/en-gb/Games/Nintendo-DS/DRAGON-QUEST-VI-Realms-of-Reverie-270594.html)

### そのまま借りないもの

- 全習得技の常時使用は、少ない技数では全員のコマンドを同じにするので採用しない。
- 職業段階を増やすだけの水増しと、弱い敵を反復するだけの熟練稼ぎは採用しない。
- 他社作品の職業名、技名、呪文名、数値、解放条件は持ち込まない。

## 本作向けの職業8段階

4段階では「覚え始めた」と「極めた」が近すぎる。6段階案でも、継承印を得た直後に
成長が終わるため、「この職のまま戦い続けて奥義を得たい」という長期目標が弱い。
全職を8段階へ統一し、4を上位職への節目、6を継承構成が開く節目、
7・8を戦況そのものを変える奥義の段階にする。

| 段階 | 報酬 | 目的 |
|---|---|---|
| ★1 | 役割を示す基本技 | 最初の戦闘から職業の遊び方が分かる |
| ★2 | 資源・対象の違う第2技 | 同じ職の中に最初の選択を作る |
| ★3 | 現職中だけ働く固有特性 | 転職後も現職の輪郭を残す |
| ★4 | 第3技＋上位職条件 | 一人前の節目。複数職を試す動機にする |
| ★5 | 条件付きの象徴技 | その職を続けた者だけの戦術を得る |
| ★6 | 既存技の派生＋継承印 | 過去職との組合せが開き、育成を構成へ変える |
| ★7 | 戦況転換技 | 行動回数・対象規則・行動順のどれかを変える |
| ★8 | マスター奥義＋マスター表示 | 職の約束を最大化し、極める目的を作る |

★4を2職で満たせば対応する上位職を解放する。★6は上位職の必須条件にせず、
前文書の「継承印」を解放する。★7・8は上位職解放にも継承枠数にも要求しない。
これにより、転職を急ぐ経路、★6で組合せを広げる経路、一職を極めて奥義を取る経路を
すべて正解にする。

必要熟練値は段階数だけで決めない。D-2の実プレイ相当シミュレーターで、
初回ランに★2〜3、複数職を試す中期に★4〜6、同じ職を意識して使い続けた先に
★7・8が来るよう測る。弱い敵を反復するだけの稼ぎを最短経路にしない。

## 戦闘へ持ち込む技

- 現職の習得済み技はすべて使用可能。
- 過去職の習得技は保持するが、出撃前に2枠だけ選んで継承する。
- `こうげき` と `ぼうぎょ` は常設し、表示上限を超えた技はサブウィンドウへ送る。
- 同じ効果の数値違いを複数習得させず、上位技は置換か派生選択として扱う。
- 継承枠の変更は拠点だけ。ラン中の拾得物や乱数で枠数を増減させない。
- ★7・8も転職後に失わないが、過去職から持ち込む場合は通常技と同じ継承枠を使う。
  奥義だけを全員へ常設して職業差を消さない。

## 技を差別化する契約

各技はデータ上で次の問いに答えられなければ追加しない。

1. **役割:** 火力、時間操作、守備、回復、資源変換、副次目的のどれか。
2. **使う条件:** どの敵、予告、HP、状態、人数なら通常攻撃より選ぶのか。
3. **代償:** MP、CTB、HP、道具、次手番の制約のどれを払うのか。
4. **対抗策:** その技だけを連打して解けない理由は何か。
5. **職業性:** 同じ性能を別職へ置いても成立するなら、まだ固有技ではない。

数値だけが違う技は統合し、次の戦術語へ割り当てる。

| 戦術語 | 役割の例 |
|---|---|
| 速攻 | 小威力だが敵の予告前に割り込める |
| 大技 | 高威力だが次手番が遅く、予告を受ける危険がある |
| 貫通 | 防御を無視し、低防御相手には通常技より損をする |
| 連撃 | 回数で障壁を割るが、防御が高い相手には弱い |
| 追撃 | 毒・睡眠・瀕死など、準備済みの対象でだけ強い |
| 中断 | 敵の予告技を遅らせるか弱める |
| 庇護 | 誰を守るかと、守り手が次に動く時刻を選ばせる |
| 副次目的 | 盗む、なだめる、調合など、撃破以外の利益を作る |

## 魔法属性の役割

- **炎:** 瞬間火力と集団への波及。長いCTBとMPを払う。
- **氷:** 威力を抑え、次手番を遅らせる。既に遅い敵には効率が落ちる。
- **雷:** 機械系と予告中の敵に強く、条件外では割高。
- **闇:** HPや次手番を代償に、吸収・瀕死追撃・MP干渉を行う。
- **回復:** 単体効率、全体救命、予防、蘇生を分け、単純な上位互換を作らない。

属性は弱点倍率だけで終わらせず、弱点でなくても用途が異なるようにする。

## 15職の戦闘上の約束

| 職業 | 固有の判断 |
|---|---|
| 戦士 | 大技を差し込むか、防御・庇護から反撃するか |
| 僧侶 | 誰をいつ治し、異常・蘇生へMPを残すか |
| 魔法使い | 属性、対象範囲、重いCTBのどれを選ぶか |
| 盗賊 | 速攻、毒、盗みで戦闘時間と利益を交換する |
| 聖騎士 | 致死予告を誰の代わりに受けるか |
| 忍者 | 煙・睡眠で準備し、条件付きの追撃へつなぐ |
| 狩人 | 獲物を指定し、種族・隊列・予告に合わせて射る |
| 魔剣士 | 物理と属性のどちらを通すかを戦闘前に決める |
| 召喚士 | 遅れて発動する広域効果を敵の行動順へ置く |
| 銃士 | 弾種で貫通・中断・煙幕を切り替える |
| 錬金術師 | 所持品を治療・妨害・爆発へ変換する |
| 賢者 | 重い代償で攻撃と支援を1手にまとめる |
| 時術師 | 行動順を正確に入れ替え、予告への猶予を作る |
| 魔獣使い | 種族技となだめるで撃破以外の結末を選ぶ |
| 遊び人 | 決定的に引いた複数候補から危険な一手を選ぶ |

## ★7・8の奥義配置

名称は仮称。狙いは「威力が20%高い技」ではなく、取る前にはできなかった手順を
可能にすること。★7は戦闘中のルールを一つ変える技、★8はその職の判断を一手へ
凝縮したマスター奥義とする。

| 職業 | ★7 戦況転換技 | ★8 マスター奥義 |
|---|---|---|
| 戦士 | **反攻陣** — 次の手番まで味方をかばい、受けた総被害を選んだ敵への反撃へ変える | **百戦連破** — 撃破後の残り打撃を次の敵へ送る連撃。単体大技と集団掃討を一手で選び直す |
| 僧侶 | **清浄圏** — 味方全体を回復し、悪性状態を優先順に一つずつ解く | **還命の鐘** — 倒れた仲間を全員起こし、生存者には致死傷を一度だけ耐える加護。1戦1回、使用後はMPが尽きる |
| 魔法使い | **弱相看破** — 敵一体の耐性をすべて開示し、次の属性魔法だけ耐性を貫く | **四象崩落** — 炎・氷・雷・闇を順に放ち、各発が別々に弱点と耐性を見る。長いCTBと大MPを払う |
| 盗賊 | **影ぬすみ** — 攻撃と盗みを同時に行い、取り尽くした敵からは次手番を盗む | **時さらい** — 敵一体を行動表の後方へ送り、そのぶん指定した味方一人を前へ出す。1戦1回 |
| 聖騎士 | **不落陣** — 次の手番まで全員をかばい、肩代わりした攻撃ほど自身の守りが増す | **誓命の盾** — 味方全体へ致死傷を一度だけ1HPで耐える誓い。発動した人数ぶん自身の次手番が遅れる |
| 忍者 | **影身** — 分身二体が次の単体攻撃を肩代わりする。全体攻撃では消えず、防げない | **千影崩し** — 生きている敵へ打撃を配り直す六連撃。倒した相手へ残り回数を捨てない |
| 狩人 | **狩標** — 獲物を一体指定し、HP・弱点・戦利品・予告を開示。味方の単体攻撃がその敵を追尾する | **天矢の雨** — 八本の矢を生存敵へ順に配る。撃破時は残りが次へ移り、高防御には一発ごとに止められる |
| 魔剣士 | **相克刃** — 攻撃時に炎・氷・雷・闇から一つを選び、物理と属性の通る側で傷を計算する | **四相連刃** — 四属性を一発ずつ重ねる連撃。万能ではなく、各発が相手の耐性を個別に受ける |
| 召喚士 | **守護獣契** — 攻撃・回復・庇護の一体を行動表へ呼び、発動前に倒されないよう時間を読む | **星獣列座** — 三体の召喚を異なる時刻へ予約する。即効性はないが、敵の予告をまたいで戦場を作り替える |
| 銃士 | **封機弾** — 防御を貫く一射。予告中の技に当てたときだけ敵の次行動を中断する | **全弾解放** — 一体へ貫通六連射。使用後は装填が終わるまで通常攻撃と防御しか選べない |
| 錬金術師 | **連成調合** — 所持品二つを戦闘中だけ一つの治療・煙幕・爆薬へ組み替える | **賢炉転化** — 消耗品一つを、味方全体の回復と敵全体の弱体へ同時変換。素材種で結果が変わる |
| 賢者 | **術式再演** — 直前に味方が使った魔法を、対象を保ったまま重いMPで再演する | **双環詠唱** — 習得済み魔法を二つ選び、指定順に一手で使う。両方のMPと重いCTBを払い、奥義の再帰選択は禁止 |
| 時術師 | **刻交換** — 行動表にいる二者の次手番を入れ替える。敵味方をまたいで選べる | **零刻界** — 味方全員の次手番を現在時刻へ寄せる。1戦1回、術者はMPを失って最後尾へ下がる |
| 魔獣使い | **なだめる** — 瀕死の獣を撃破せず帰し、種族素材と再召喚候補を得る | **百獣行** — 敵種と戦況から決定的に選ばれた獣三体が、攻撃・妨害・救援を順に行う |
| 遊び人 | **運命札** — `DetRng`で先に引いた二つの結果を見せ、どちらを起こすか選ぶ | **幕返し** — 戦闘の最大の不利（戦闘不能・瀕死・人数差・行動差）を一つ判定し、対応する大逆転を起こす。1戦1回 |

### 奥義の共通契約

- ★7・8の全30技は、行動回数、対象の配り方、行動表、資源変換、勝利条件の
  いずれかを変える。倍率だけの上位互換は置かない。
- 一手で二行動する技は、それぞれの対象・MP・属性・失敗条件を個別に解決する。
  1発目で戦闘が終わったら2発目は撃たず、払わなかった分の資源も明示する。
- 連撃の対象再配分は、生存者をID昇順に並べたうえで `DetRng` または明記した
  優先規則だけで決める。同じシードなら標的と回数も一致させる。
- 1戦1回、装填、素材、全MP、長いCTBなど、連打を最適解にしない代償を技ごとに持つ。
- 奥義から別の奥義を再演・二重詠唱できない。再帰と無限行動をデータ検査で拒否する。
- コマンド画面には結果だけでなく、二つの対象、総MP、総CTB、残り使用回数、
  装填や素材不足を決定前に表示する。

## 検証

- 名前と実効果が一致しない4技を先にfixture化し、修正前に失敗するテストを作る。
- 全技に役割IDを持たせ、同一の役割・条件・対象・代償だけの技を検査で弾く。
- 15職すべてで、現職技だけの戦術と継承2枠を使った戦術を最低1件ずつテストする。
- ★7・8の全30技に、発動成功、条件不足、1戦制限、対象消滅、
  複合行動の途中決着を含むfixtureを置く。
- オートは全役割を常用する必要はないが、適切なfixtureでは選べることを確認する。
- 同じシード、職業、継承枠、入力列から戦闘結果と行動順が一致すること。
- 数値決定はD-2完了後の実プレイ相当 `balance.gd` で行い、技数では調整しない。
