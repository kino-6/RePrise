# 職業・特技・魔法の再設計案

## 診断

現状は15職×4段階で60個の習得枠があるが、報酬になっている技IDは37個だけで、
23枠は別職との重複になっている。共有そのものより、共有された技の多くが
威力・MP・対象範囲・行動コストだけの差であることが問題。

- `つらぬき` は防御無視用の引数が実行経路から渡されず、普通の単体物理攻撃。
- `ときとまれ` は敵全体への通常の鈍足、`ひっさつ` は条件なしの高威力攻撃。
- `けむりだま` は敵全体への鈍足で、`あそぶ` と `きまぐれ` は同じ効果表を使う。
- 炎・氷・雷は主に弱点倍率と対象範囲の違いで、属性ごとの戦い方がない。
- 習得済みの全技を常時使えるため、転職を重ねるほど現職より過去職の強技が目立つ。
- オートは攻撃をほぼ「威力×回数÷行動コスト」で選び、妨害や副次目的を評価しない。

## 参考作品から借りる構造

### FF5から借りるもの

公式説明では、ジョブレベルで能力を習得し、それらを組み替えることで
独自の構成を作る点が中心に置かれている。ここから「現職の個性を土台にして、
過去職から選んだ一部だけを足す」という構造を借りる。

- 現職だけで最低限の役割が成立する。
- 過去職の習得物は失わないが、戦闘へ持ち込むものは選ぶ。
- 強さより、異なる役割同士の組み合わせが報酬になる。

参考:
[FF5公式](https://www.jp.square-enix.com/game/detail/ff5/) /
[FF5アドバンス公式](https://www.jp.square-enix.com/archive/ff5a/)

### DQ6から借りるもの

公式説明では、職業ごとの熟練で特技・呪文を覚え、転職後も保持すること、
基本職のマスターから上位職が開くことが示されている。ここから「寄り道も将来の
進路になる長期育成」と「職業を極める明確な目的」を借りる。

- 熟練はランをまたいで残り、途中で転職しても無駄にならない。
- 複数職の節目が上位職への経路になる。
- 各職は固有の技と役割を持ち、進路を選ぶ情報を事前に見せる。

参考:
[DQ6公式](https://www.jp.square-enix.com/dqsp/dq6/system/) /
[Nintendo公式の職業解説](https://www.nintendo.com/en-gb/Games/Nintendo-DS/DRAGON-QUEST-VI-Realms-of-Reverie-270594.html)

### そのまま借りないもの

- 全習得技の常時使用は、少ない技数では全員のコマンドを同じにするので採用しない。
- 職業段階を増やすだけの水増しと、弱い敵を反復するだけの熟練稼ぎは採用しない。
- 他社作品の職業名、技名、呪文名、数値、解放条件は持ち込まない。

## 本作向けの職業6段階

4段階では「覚え始めた」と「極めた」が近すぎる。全職を6段階へ統一し、
4を上位職への節目、6を任意だが強く欲しくなるマスター報酬にする。

| 段階 | 報酬 | 目的 |
|---|---|---|
| ★1 | 役割を示す基本技 | 最初の戦闘から職業の遊び方が分かる |
| ★2 | 資源・対象の違う第2技 | 同じ職の中に最初の選択を作る |
| ★3 | 現職中だけ働く固有特性 | 転職後も現職の輪郭を残す |
| ★4 | 第3技＋上位職条件 | 一人前の節目。複数職を試す動機にする |
| ★5 | 条件付きの象徴技 | その職を続けた者だけの戦術を得る |
| ★6 | 継承印＋マスター表示 | 極める目的。能力値ではなくルールを変える |

★4を2職で満たせば対応する上位職を解放する。★6は上位職の必須条件にせず、
前文書の「継承印」を解放する。これにより、転職を急ぐ経路と一職を極める経路を
どちらも正解にする。必要熟練値は段階数から決めず、実プレイ相当シミュレーターで
「最初の1ランで★2〜3、継続した2ラン前後で★6」を目安に測る。

## 戦闘へ持ち込む技

- 現職の習得済み技はすべて使用可能。
- 過去職の習得技は保持するが、出撃前に2枠だけ選んで継承する。
- `こうげき` と `ぼうぎょ` は常設し、表示上限を超えた技はサブウィンドウへ送る。
- 同じ効果の数値違いを複数習得させず、上位技は置換か派生選択として扱う。
- 継承枠の変更は拠点だけ。ラン中の拾得物や乱数で枠数を増減させない。

## 技を差別化する契約

各技はデータ上で次の問いに答えられなければ追加しない。

1. **役割:** 火力、時間操作、守備、回復、資源変換、副次目的のどれか。
2. **使う条件:** どの敵、予告、HP、状態、人数なら通常攻撃より選ぶのか。
3. **代償:** MP、CTB、HP、道具、次手番の制約のどれを払うのか。
4. **対抗策:** その技だけを連打して解けない理由は何か。
5. **職業性:** 同じ性能を別職へ置いても成立するなら、まだ固有技ではない。

数値だけが違う技は統合し、次の戦術語へ割り当てる。

| 戦術語 | 役割の例 |
|---|---|
| 速攻 | 小威力だが敵の予告前に割り込める |
| 大技 | 高威力だが次手番が遅く、予告を受ける危険がある |
| 貫通 | 防御を無視し、低防御相手には通常技より損をする |
| 連撃 | 回数で障壁を割るが、防御が高い相手には弱い |
| 追撃 | 毒・睡眠・瀕死など、準備済みの対象でだけ強い |
| 中断 | 敵の予告技を遅らせるか弱める |
| 庇護 | 誰を守るかと、守り手が次に動く時刻を選ばせる |
| 副次目的 | 盗む、なだめる、調合など、撃破以外の利益を作る |

## 魔法属性の役割

- **炎:** 瞬間火力と集団への波及。長いCTBとMPを払う。
- **氷:** 威力を抑え、次手番を遅らせる。既に遅い敵には効率が落ちる。
- **雷:** 機械系と予告中の敵に強く、条件外では割高。
- **闇:** HPや次手番を代償に、吸収・瀕死追撃・MP干渉を行う。
- **回復:** 単体効率、全体救命、予防、蘇生を分け、単純な上位互換を作らない。

属性は弱点倍率だけで終わらせず、弱点でなくても用途が異なるようにする。

## 15職の戦闘上の約束

| 職業 | 固有の判断 |
|---|---|
| 戦士 | 大技を差し込むか、防御・庇護から反撃するか |
| 僧侶 | 誰をいつ治し、異常・蘇生へMPを残すか |
| 魔法使い | 属性、対象範囲、重いCTBのどれを選ぶか |
| 盗賊 | 速攻、毒、盗みで戦闘時間と利益を交換する |
| 聖騎士 | 致死予告を誰の代わりに受けるか |
| 忍者 | 煙・睡眠で準備し、条件付きの追撃へつなぐ |
| 狩人 | 獲物を指定し、種族・隊列・予告に合わせて射る |
| 魔剣士 | 物理と属性のどちらを通すかを戦闘前に決める |
| 召喚士 | 遅れて発動する広域効果を敵の行動順へ置く |
| 銃士 | 弾種で貫通・中断・煙幕を切り替える |
| 錬金術師 | 所持品を治療・妨害・爆発へ変換する |
| 賢者 | 重い代償で攻撃と支援を1手にまとめる |
| 時術師 | 行動順を正確に入れ替え、予告への猶予を作る |
| 魔獣使い | 種族技となだめるで撃破以外の結末を選ぶ |
| 遊び人 | 決定的に引いた複数候補から危険な一手を選ぶ |

## 検証

- 名前と実効果が一致しない4技を先にfixture化し、修正前に失敗するテストを作る。
- 全技に役割IDを持たせ、同一の役割・条件・対象・代償だけの技を検査で弾く。
- 15職すべてで、現職技だけの戦術と継承2枠を使った戦術を最低1件ずつテストする。
- オートは全役割を常用する必要はないが、適切なfixtureでは選べることを確認する。
- 同じシード、職業、継承枠、入力列から戦闘結果と行動順が一致すること。
- 数値決定はD-2完了後の実プレイ相当 `balance.gd` で行い、技数では調整しない。
