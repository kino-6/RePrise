# 音楽・効果音の設計

音は「懐かしい RPG らしさ」だけでなく、この作品の構造を聞かせる。
銀の砦は世界の外に残り、訪れた世界は一度きりで閉じる。それでも出会った人物、
交わした約束、成功も失敗も戦記として残る。この三層を同じ短い旋律で結ぶ。

## 共通の旋律

核は `ラ―ド―ミ―シ` の四音。音価を `付点四分―八分―四分―四分` として、
単なる短三和音の分散ではなく、最初の音に「立ち止まって見る」重さを置く。
最後のシは落ち着かず、旅や物語では先を聞きたくなる形で止める。生還や戦記では
最後だけラへ帰し、「最後まで見届けた」感触を作る。

- 砦・題名: 遠くから思い出すように遅く鳴らす
- 世界・通常戦: 歩みを止めないリズムへ変える
- 物語: 楽器を減らし、一人と一つの約束へ焦点を寄せる
- 主戦: 帝国機械の反復音型に飲み込ませ、終盤で旋律が押し返す
- 戦記: 勝敗を祝福・断罪せず、記録としてラへ帰す

同じ四音を全曲へそのまま貼らない。断片化、音価の伸縮、音域、和声、終止、
担当楽器を変え、「人物が動機を引き受けた」「機械が動機を反転した」
「記録の中でだけ解決した」という物語上の関係を聞かせる。

## 後期 16-bit の編成規約

後期 SFC らしさは矩形波へローパスを掛けることではなく、少ない発音数で
木管・弦・金管・撥弦の役割を読ませることに置く。

- 通常は主旋律 / 低音 / 和声 / 応答 / 打楽器のうち 3〜5 役。同時に常駐させない
- 生の矩形波・鋸歯状波を通常の主旋律にしない。機械の短い色としてのみ許可する
- 三和音パッドを全小節へ敷かない。開いた五度、add2 / 6th、sus、ペダルを使う
- 低音はルート八分連打を避け、反行、先取り、休符を含む第二の旋律にする
- 「空いているから分散和音で埋める」を禁止し、主旋律が休む場所だけ応答を置く
- 8 小節ごとに音域 / リズム / 楽器 / 和声 / 密度のうち 2 項目以上を変える
- 音符、編曲、ミックスの順で直す。エコーは旋律や構成の弱さを補修しない

この規約の根拠と作業 Gate は個人 Skill
`compose-sfc-rpg-bgm` の `references/composition-principles.md` に置く。

## BGM の役割

| ファイル | 場面 | 狙い |
|---|---|---|
| `title` | 題名 | 世界の外から、まだ知らない世界を眺める静けさ |
| `stronghold` | 銀の砦 | 毎ラン変わらない唯一の場所。威厳より帰還の安心 |
| `world` | ワールド | 一度きりの土地を先へ進む旅。明るさの下に未解決音を残す |
| `town` | 町 | 閉じる世界の中にある仮の故郷。小編成で人の温度を出す |
| `cave` | 洞・寄り道 | 世界の傷口へ降りる空洞感。音数を抑え、環境音の余白を残す |
| `story` | コア物語 | 人物・約束・選択へ注意を絞る。心拍に近い低音 |
| `battle` | 通常戦 | 短い判断を急がせつつ、旅の旋律との連続性を保つ |
| `boss` | 主・帝国機械 | 規則的な低音と金属的打音。機械の圧力に人の旋律が抗う |
| `chronicle` | 生還・全滅後 | 結果ではなく、見届けた事実が砦へ残る終止 |

`descent` は旧画面・古い参照との互換用に生成を続けるが、新しい場面割り当てでは
`world` と `cave` に分ける。

## 現行アレンジの識別点

| 曲 | 拍・編成 | 抜き差し |
|---|---|---|
| `title` | 遅い 4 拍、合唱 / ハープ / 木管 | 合唱は二小節単位。旋律のない小節を残す |
| `stronghold` | 儀式的 4 拍、オーボエ / 弦 / 控えめな金管 | 節末だけティンパニ。旋律の同音重ねをしない |
| `world` | 軽い 4 拍、木管 / 弦 / 皮物 | B 部では打楽器を全て抜いて景色を開く |
| `town` | 3 拍、ピアノ / 撥弦 / 木管 | 常時パッドを使わない小編成 |
| `cave` | 遅い 4 拍、低音 / 開いた弦 / 鐘 | 二小節の持続と旋律の欠落で空洞を作る |
| `story` | 遅い 4 拍、合唱 / ハープ / 木管 | 心拍はノイズでなく二小節ごとの低い撥弦 |
| `battle` | 速い 4 拍、金管 / 木管 / 皮物 | B 部は長い旋律と低金管の応答へ退く |
| `boss` | 速い 4 拍、低金管 / 弦 / 機械的低音 | 八分音符の壁を四つの歯へ減らし、人の木管が反撃する |
| `chronicle` | 遅い 4 拍、弦 / ハープ / 木管 | 撥弦は小節後半だけ。結末より記録を前へ出す |

## 新しい場面 SE

| ファイル | 意味 |
|---|---|
| `depart` | 砦から世界へ渡る |
| `event` | 通常イベントとの遭遇 |
| `story_open` | コア物語の人物・約束が現れる |
| `story_choice` | 選んだ手を世界が記憶する |
| `seal_break` | 世界を縛る封が解ける |
| `boss_gate` | 主の機械・城門が起動する |
| `victory` | 約束が最後まで届く |

カーソルや攻撃・属性・状態異常など既存 SE は残し、意味の違う場面だけ専用音を
足す。同じ決定音の使い回しで、物語上の重さが平らになるのを避ける。

## 技術上の規約

- 32 kHz / 16 bit / stereo
- BGR555 と同じく、生成器側で時代の制約を強制する
- 倍音表と ADSR でサンプル楽器の役割を作ってから、一次ローパスで高域を丸める
- 左右で異なる遅延のフィードバックエコーを通す
- BGM のリリースを次周冒頭へ折り返し、エコーへ過去の周回を与える。
  WAV 末尾へ無音・残響だけの tail は付けない
- WAV は `tools/gen_audio.py` から決定的に再生成する
- `tools/verify_audio.py` で必須ファイル、無音、クリップ、直流成分、音量起伏、
  冒頭和音、ループ境界の段差、無音 tail を検算する
- 場面転換時は二つの再生器を短くクロスフェードし、曲の切断音を出さない
