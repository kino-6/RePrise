# 町生成ルール

## 目的

町は迷路ではなく、次の攻略へ向けて情報と準備を整える安全地帯。
生成のたびに景観は変えても、入った直後に「どこから来たか」「どこへ戻るか」
「まずどちらへ進めばよいか」を考え直させない。

## 固定するもの

### 入口

- 町の入口は常に**南辺中央**へ置く。
- 現行データでは町へ入るタイルと世界へ戻るタイルが同じなので、
  `TownMap.exit_pos = Vector2i(width / 2, height - 1)` を入口座標とする。
- `start_pos` は入口の1マス北へ固定する。
- 内部表現は方角を正規化した見取り図とし、世界地図で町へ接近した方向は持ち込まない。
- 入口から半径2マスを到着余白にし、建物、NPC、看板、ランダム装飾を置かない。
- 入口から中央広場まで、途切れない主街路を先に引く。最初の3マスは分岐させない。

入口固定は町を同じ形にするためではなく、毎回同じ読み始めを保証するためのもの。
乱数で変えるのは入口の先にある街路、広場、地区、建物、住民とする。

### 必須機能

- 宿、店、町固有の仕事場、出口、情報役へ必ず到達できる。
- 宿・店・仕事場は地図上に短い札を出し、入口または中央広場から少なくとも1つを
  視認できる。札は施設の入口を隠さず、利用済みの仕事場は色を落とす。
- 入口から広場までの主街路をNPCが塞がない。
- 出口へ戻る経路には施設利用、会話、イベント完了を要求しない。

### 町でできること

- 宿は全回復と毒の治療、店は購入、仕事場は生業ごとの旅支度を担当し、役割を重ねない。
- 仕事場は町ごとに1回だけ利用でき、道具の支給・一定歩数の強化・店の在庫追加・
  道の安全化・主の初動遅延のいずれかを、表示だけでなくラン状態へ反映する。
- 宿・店の脇は宝箱タイルを看板へ流用せず、専用の案内札を使う。本物の宝箱は
  広場から少し外れた空地に「旅人箱」として1個だけ置き、道具とゴールドを一度だけ渡す。
- NPCは無作為に散らさず、宿の主人は宿、商人は店、生業と問題に関わる役は仕事場、
  案内役は広場の近くへ置く。入口と主街路を塞ぐ場合は近傍の空きマスへずらす。
- 会話は「その人物・町に固有の一言」と「現在の手持ちや目的地に基づく実用情報」の
  最大2行に分ける。地図を更新した場合は更新対象まで明記し、決定か取消まで窓を残す。

## 先に決める町の設定

`TownProfile` を間取りより先に `DetRng` で決める。

| 項目 | 反映先 |
|---|---|
| 生業 | 建物、作業場、商品、住民の役 |
| 支配者 | 門、役所、警備、禁止事項、台詞 |
| 現在の問題 | 壊れた場所、空き区画、避難民、イベント |
| 目印 | 広場の形、塔、樹木、炉、水場、機械 |
| 生物相 | 素材、色、植生、町外縁、住民候補 |
| 危険度 | 防壁、警備、損傷、物資不足 |

同じ世界の町同士では、生業・現在の問題・目印の組を重複させない。
NPCの役と台詞は、配置後に独立抽選せず同じ `TownProfile` から作る。

## 生成順

1. 寸法と `TownProfile` を決める。
2. 南辺中央の入口、直上の開始位置、到着余白を予約する。
3. 町固有の目印を持つ中央広場を置き、入口から主街路で結ぶ。
4. 広場から宿、店、出口案内へ枝道を伸ばす。
5. 生業と支配者に合う地区・建物を置く。
6. 現在の問題を空き区画、損傷、封鎖、NPC分布へ反映する。
7. 必須役、生物相に合う役、町固有役の順で、役に対応する施設の近くへNPCを置く。
8. 到達性と案内性を検査してから装飾を置く。

到達性検査に失敗した町を部分修復して続行しない。同じ入力から生成順を変えず、
失敗した構造を棄却して次の決定的な候補を使う。

## 多様性の作り方

入口座標、町の寸法、NPC座標だけを違いとして数えない。次を比較する。

- 広場の位置と形
- 主街路からの分岐グラフ
- 宿・店・町固有施設の相対配置
- 目印と生業区画
- 通行可能領域の輪郭

多様性検査では固定入口と到着余白をマスクし、内部タイルと施設の相対配置を
正規化した指紋を使う。入口を四辺へ振っただけの町を別形として数えない。

## Gate

- 100シードすべてで入口が南辺中央、開始位置が直上にある。
- 入口周辺5×3マスにNPC・建物・ランダム装飾が無い。
- 入口から広場までの最初の3歩が一意で、その先から宿・店へ案内できる。
- 宿、店、情報役、出口へ到達でき、NPCを押してどかす必要がない。
- 町固有の仕事場へ到達でき、初回利用でラン状態が変わり、同じ町で報酬を再取得できない。
- 案内札と旅人箱が別の絵・当たり判定で、旅人箱へ横から触れられ、再入場後は復活しない。
- 宿の主人・商人・生業役・案内役が、それぞれ対応する施設または広場の規定距離内にいる。
- 同一シード・危険度・生物相・町IDから同一の `TownProfile` と地図が生成される。
- 同一世界の4町で、生業・問題・目印の組が重複しない。
- 固定領域を除いた内部指紋が100シード中、定めた最低種類数を下回らない。
- `--shot=town` で入口、主街路、目印、宿、店、仕事場、NPC色を同じ画面内で目視する。
- `--shot=town_talk` と `--shot=town_facility` で、会話2行・閉じ方・実効果が
  512×320内に収まり、下段の仲間情報を隠さないことを目視する。
- 操作を追うときは `--inspect=town_talk`、初回と再利用を比べるときは
  `--inspect=town_facility` / `--inspect=town_facility_repeat` へ直接入り、
  秒数自動プレイは町を含む全体導線の回帰だけに使う。
- 旅人箱は `--inspect=town_chest` / `--inspect=town_chest_opened` で、
  閉じた箱と実際の報酬窓を個別に確認する。
