# ワールドローグライク設計

**1 ラン = 1 つの世界。** 世界そのものが毎回作り直される。
不思議のダンジョン系ではない。**歩けるワールドマップを持つ、SFC 期の JRPG の形**で、
そのワールドが使い捨てになる。

前提（なぜ世界が毎回変わるのか）は `docs/premise.md`。

---

## 1. いちばん大事な読み替え：「階」ではなく「危険度」

今の実装は地下 10 階の潜行で、`floor_number` が 100 か所に出てくる。
だが中身を見ると、**そのほぼ全部が「難度のスカラー」としてしか使われていない。**

| 使われ方 | どこ |
| --- | --- |
| 敵プールの門（`floor_min` / `floor_max`） | `database.gd` |
| 敵の能力倍率 `100 + (n-1)*11 + (n-1)²/14` | `encounter.gd:70` |
| 戦利品と宝箱の等級・数 | `battle_system.gd` / `dungeon_generator.gd` |
| 出店の品揃え | `shop_view.gd` |
| 表示（「地下 N 階」） | `explore_hud.gd` |

つまり **`floor_number` を「危険度 1..10」に読み替えるだけで、
数値表（`data/*.json` の `floor_min`）も難度曲線もそのまま生き残る。**
実測して合わせ込んだ「主に挑めた 31% / 倒した 19%」も捨てずに済む。

危険度は**出発地点からの距離**で決まる。

```
危険度 = 1 + floor(9 * (出発からの陸路距離 / 終点までの陸路距離))
```

出発が 1、終点が 10。これで今の 10 階ぶんの曲線が、そのまま
「世界の端から端まで」に化ける。遠くへ行くほど危ない、という DQ の作法そのもの。

洞（ダンジョン）の中は `その洞の危険度 + 階 - 1`（上限 10）。
浅い土地の洞でも、潜れば少し危なくなる。

## 2. 世界の形

```
┌──────────────────────────────┐  64 x 48 タイル（16px）
│ ~~~~~~~~~~~~~~~~~~~~~~~~~~~~ │  画面は 32 x 20 ぶんを映して追従
│ ~~ 門  町      森森    ^^^^~ │
│ ~~  @      洞   森   ^^ 城 ~ │  門 = 拠点から着く場所（危険度 1）
│ ~~   草原草原      ^^^^^   ~ │  城 = 終点。主が居る（危険度 10）
│ ~~~~~~~~~~~~~~~~~~~~~~~~~~~~ │
└──────────────────────────────┘
```

- **地形**は危険度の帯で決まる。草原 → 森 → 山/荒地 → 雪原。
  素材はすでにある（`assets/tiles/` の 5 種）ので、新しく描かなくても回る。
- **町**（3〜4）… 出店・宿・仲間。安全地帯。今の `shop_view` がそのまま入る。
- **洞**（3〜5）… 今の `DungeonGenerator` をそのまま使う。1〜3 階。寄り道。
  本筋から外れたところに置く。**行かなくても終点に着ける**のが大事で、
  「寄るか、急ぐか」が判断になる。
- **城**（1）… 終点。踏むと主戦。勝てば生還、負ければ全滅。

## 3. 画面の階層

```
タイトル → 拠点（世界の外）→ 門 → ワールド ⇄ 町
                                    ⇄ 洞（1〜3 階）
                                    → 城（主戦）→ 戦記 → 拠点
```

`main.gd` の Mode に `WORLD` を足す。今の `EXPLORE` は
**「拠点地の中」**（洞の中）に降格し、そのまま使う。

## 4. 実装の分け方

`ExploreView`（254 行）は歩き・カメラ・エンカウント・描画を持っていて、
**地図の中身に依存していない。** ここはワールドでも洞でも同じものを使う。
そのために地図の型だけ揃える。

```
FieldMap（新規・共通）   … 格子・通行判定・描画タイル・経路探索
 ├ DungeonMap           … 部屋 / 階段 / 宝箱 / 出店 / 最終階
 └ WorldMap             … 拠点地（町・洞・城）/ 出発 / 終点 / 危険度の場
```

`ExploreView.map` の型を `FieldMap` に上げれば、両方を歩ける。
`route()` も共通なので、自動プレイの「目的地へ歩く」もワールドで動く。

## 5. 何を捨てるか

- `FINAL_FLOOR = 10` と「主の間の扉」… 終点は城になる
- `Terms.FLOOR`（「地下 %d 階」）… 危険度と地方の名に置き換える
- `docs/premise.md` の奈落… 世界の外に拠点がある形へ書き直す（済）

## 6. 段取り

1. `FieldMap` を切り出し、`DungeonMap` をその子にする（見た目の変化なし）
2. `WorldGenerator` / `WorldMap`（陸地・危険度・拠点地の配置）
3. `main.gd` に `WORLD` を足し、門 → ワールド → 城 まで通す
4. 町（出店・宿）と洞（既存ダンジョン）への出入り
5. 危険度への読み替え（`floor_number` → `danger`）と表示
6. 難度の測り直し（`balance.gd` をワールド踏破率に組み替える）
7. 自動プレイをワールド対応にする

**各段で必ず遊べる状態を保つ。** まとめて壊すと、どこで壊れたか分からなくなる。
