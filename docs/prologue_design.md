# プロローグ設計

作成日: 2026-07-31

## 役目

ゲーム開始時に次の四点を、設定資料ではなく一度の事件として体験させる。

1. 一行は既に世界の命運を背負い、終局の主まで到達したこと。
2. 決着の寸前に、ひとつだった世界が異なる歴史を持つ複数の世界へ分かれたこと。
3. 開いていた銀の門だけが一行を回収し、砦が世界の外へ残ったこと。
4. 砕けた世界へ一度ずつ渡り、城の主を討つ旅が始まったこと。

説明から始めず、主と対峙した状態から始める。
プレイヤーが決定キーで最初の一撃を選び、その結果として世界分断を見る。
勝敗を選ばせる場面ではないが、自分が事件の瞬間に居たという手触りを残す。

## 世界の前提

決戦以前、世界はひとつだった。
終局の城にいた「終局の主」は、敗北する寸前に世界を分断する。
大地と人々は、異なる歴史を持つ多数の世界へ引き離される。

銀の砦は、分断時に門を開いていたため世界の外へ取り残された。
門は消えかけた世界を一つだけ捉え、一行をその世界の役として送り込める。
接続が閉じれば同じ世界へは二度と届かない。

砦の記録係と一行は当初、各世界の城へ根を張った主を討てば世界が保たれ、
すべての主を追えば「終局の主」へ届くと信じている。
これは出撃の動機であって、作品全体の絶対的な真相ではない。
横断シナリオでは、主が砦からの流入を封じていた可能性や、
砦自身が救援先を選別している疑いを提示できる。

## 八拍

| 拍 | 絵 | プレイヤーが知ること |
| --- | --- | --- |
| 1. 終極の城 | 四人と主が対峙 | 冒険の終盤から始まる |
| 2. 宣告 | 主が分断の力を掲げる | 決着が世界全体に関わる |
| 3. 一撃 | 決定キーで斬り込む | 事件へ参加する |
| 4. 分断 | 世界と画面が砕ける | ひとつの世界が終わる |
| 5. 声 | 異なる世界の欠片が浮かぶ | 消滅していない世界がある |
| 6. 回収 | 銀の門が四人を拾う | 砦だけが残る理由 |
| 7. 遠征 | 門の向こうに異なる土地 | ランダム世界と一度限りの接続 |
| 8. 誓い | 四人が次の門へ向く | プレイヤーの当面の目的 |

## 実装契約

- 新規データではタイトル決定後、拠点より前に一度だけ再生する。
- 既に一回以上出撃している旧セーブでは、移行時に視聴済みとして扱う。
- 中断データがある場合は従来どおり中断を優先し、プロローグを挟まない。
- 最後まで進めたときだけ視聴済みを恒久セーブへ書く。
- プロローグ中に終了した場合は、次回もう一度最初から再生する。
- 表示文は `data/vocabulary.json` の `lore.prologue_*` に置き、Viewへ直書きしない。
- 既存の背景、職業スプライト、主、門エフェクトを組み合わせ、新しい画風を混ぜない。
- プロローグを見なくても、セーブ移行、デバッグ起動、ゲームロジックは成立する。
