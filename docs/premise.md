# 世界へ送られる理由

世界の前提はプロローグで確定した。演出の八拍と実装契約は
`docs/prologue_design.md`、画面へ出す文言は `src/game/lore.gd` と
`data/vocabulary.json` に置く。

## 最初の事件

決戦以前、世界はひとつだった。
一行は世界の終局を止めるため「終極の城」へ到達し、
「終局の主」へ最後の一撃を放つ。

攻撃が届く直前、終局の主は世界を分断した。
大地と人々は、異なる歴史を持つ多数の世界へ引き離された。
分断時に開いていた銀の門だけが一行を回収し、銀の砦は世界の外へ取り残された。
主自身も砕けた世界のどこかへ逃れている。

一行が銀の砦から遠征を続ける当面の目的は三つ。

1. 銀の門との接続が途切れる前に、その世界を救援する。
2. 城を支配する主を討ち、その世界を守る。
3. 異なる主を追い、最初に世界を砕いた存在へ届く。

「主を討つことが本当に救済か」「銀の砦は救援先を公平に選んでいるか」は、
開始時点の一行には分からない。ここは複数ランをまたぐ物語で疑い直せる。

## ゲームの仕組みとの対応

| 仕組み | 世界内の理由 |
| --- | --- |
| 世界がランごとに丸ごと作り直される | 門が毎回、異なる世界の欠片を捉える |
| 同じ世界へ二度と行けない | 銀の門が接続できるのは閉じるまでの一度だけ |
| 銀の砦だけが残る | 分断時に門を開いていたため世界の外へ取り残された |
| 地形・町・主が毎回違う | 欠片は異なる歴史を持つ独立した世界へ育った |
| レベル・装備・ゴールドを失う | 一行は接続先の世界から身体と役を借りる |
| 職業熟練と覚えた技が残る | 返る身体ではなく、世界外にいる本人の手つきとして残る |
| 全滅しても資源が入る | 踏んだ土地と選択の記録だけは銀の砦へ帰る |
| 主を討てば生還、討てなければ世界を失う | 主戦が接続を保てる最後の時点になる |

## 主人公と一行

プロローグの中心は初期一行のアレンだが、勝利を一人の血筋へは結び付けない。
セラ、ノア、キリも最初の決戦と分断を経験した当事者である。
後から名簿へ加わる者は、別世界から回収された者、砦の住民、
過去の遠征者として参加できる。全員へ同じ出自を強制しない。

## 画面に出す量

前提を一度に説明するのは初回プロローグだけ。
以後は次の短い反復で、遊びと設定の対応を思い出させる。

1. 拠点で「出撃する」を選んだときの三行。
2. 資源の説明。
3. 戦記で、世界が保たれたか失われたか。
4. 複数ランをまたぐ物語で、最初の理解を疑い直す。

タイトル画面は題字と一行だけの方針を保つ。
タイトル決定後、初回だけプロローグを挟み、その後は直接銀の砦へ入る。
