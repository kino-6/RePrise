# 戦闘設計のよりどころ

往年の JRPG を調べて、「何が戦闘を面白くしているのか」を実装できる形にまとめたもの。
以後の戦闘まわりの変更は、思いつきではなくここを根拠にする。

出典は末尾。

---

## 1. いまの戦闘が単調な理由（診断）

調査で繰り返し出てくる指摘が、そのまま当てはまっていた。

> 位置取りも環境効果も意味のあるリソース管理も無いコマンド戦闘は、
> 自動化できてしまう（＝人が選ぶ意味がない）。

この作品の戦闘を、実際に自動操縦（`tests/balance.gd`）が最後まで回せてしまう事実が
その証拠になっている。具体的には次が欠けていた。

| 欠けているもの | 起きること |
|---|---|
| 弱点・耐性 | 敵が変わっても最適な手が変わらない。毎回「こうげき」 |
| 状態異常 | 攻撃と回復以外の選択肢が無い |
| 範囲攻撃 | 敵が何体いても同じ手。数の脅威が生まれない |
| 対象選択 | 回復を誰に配るかという判断が消える |
| 敵の行動の予告 | 相手を見て手を変える理由が無い |
| 装備 | 戦闘前の準備という層が無い |
| 盗む等の副次目的 | 「倒す」以外の勝ち方が無い |

---

## 2. 面白さの素（調査からの抽出）

### 2.1 リソースは 2 軸以上にする

MP だけだと「MP があるなら強い呪文、無いなら通常攻撃」の一次関数になる。
最低でも次の 3 つが同時に効くようにする。

- **MP** — ラン全体で枯れていく。回復手段は有限
- **行動コスト（この作品の核）** — 重い手ほど次の手番が遅れる
- **道具** — 消耗品は個数が有限。戦具はなくならないが回復系は1戦1回。どちらも1手番かかる

強い手が「MP も時間も食う」形になっていると、毎ターン天秤にかけることになる。

### 2.2 弱点・耐性は「効く手が敵ごとに変わる」ための装置

FF6 は 8 属性に対して **倍・半減・無効・吸収** の 4 段階を持つ。
狙いは属性そのものではなく、**敵ごとに正解の手が変わること**にある。
これが無いと、プレイヤーは最も強い 1 手を覚えた時点で考えるのをやめる。

この作品では属性を **4 つ（炎・氷・雷・闇）** に絞る。
24x32 のドット絵と 512x320 の画面で見分けが付く上限がこのあたり。

### 2.3 状態異常は「行動順に効くもの」を優先する

CTB（＝仮想時間軸の優先度キュー）を採用しているので、**時間に触る効果が最も強く効く**。
他作品では「ターンを飛ばす」でしかない効果が、この作品では行動順バーの見た目として現れる。

| 効果 | CTB での意味 |
|---|---|
| ねむり | 次の手番が来ても行動せず、さらに後ろへ回る |
| まひ | 一定時間、キューから外れる |
| どんそく / かそく | 以後の行動コストが増減する（バーの並びが変わる） |
| どく | 手番が来るたびに削れる（＝速い者ほど早く減る） |

### 2.4 グループ攻撃は「数が多いほど 1 体あたりが減る」

DQ の仕様がそのまま設計の答えになっている。

> グループ攻撃呪文は相手の数が 2 体以下、全体攻撃呪文は 3 体以下だと、
> 相手の数が少ないほどダメージが増える。

つまり **範囲攻撃は敵が多いときだけ得**で、単体には単体攻撃が勝つ。
これがあると「敵の数を見てから手を選ぶ」が成立する。逆に減衰が無いと範囲攻撃が常に最適になり、
選択が消える。

### 2.5 敵の行動を予告する

「相手を見て手を変える」を成立させるには、相手の手が事前に見えている必要がある。
この作品は**行動順バーを既に持っている**ので、そこに敵の次の行動を出すだけでよい。
他の JRPG より安く実装できて、効き目は大きい。

### 2.6 消耗戦（ダンジョン全体で 1 つの戦い）

HP と MP が戦闘をまたいで持ち越されるからこそ、1 回の戦闘での節約が意味を持つ。

> 体力や特殊能力が戦闘間で自動回復しないため、傷と疲労が複数の戦闘にまたがって蓄積する。

この作品は既にそうなっている（回復手段は道具と出店のみ）。**この構造は崩さない。**

なくならない戦具は、この消耗戦に対する例外ではなく、毎戦の手札を増やす層にする。
固定回復は1戦1回、無制限の攻撃は通常攻撃より控えめにし、HP・MPを際限なく戻せる品は
置かない。宝箱で拾えるほか、恒久強化では解放済み候補から1個だけ持ち込む。
同じ品を重ねても使用回数は増えず、イベントの「どうぐを渡す」代価にも使えない。

武器・防具の戦闘中使用も同じ契約へ通す。装備している本人だけが使え、1戦制限は
品ごとではなく使用者と品の組で数える。これで装備が能力値だけでなくコマンドの選択になる。

### 2.7 自動戦闘は「作戦」で持たせる

DQ4 の作戦が優秀な理由は、**プレイヤーの意図を 1 語で渡せる**こと。

- **ガンガンいこうぜ** — 最大火力。MP を湯水のように使う
- **いのちだいじに** — HP が減っていれば回復を最優先
- **みんながんばれ** — 攻撃と回復のバランス

「AI は人間より賢くはないが、回復だけは人間より速い（自分の手番で最新の HP を見て選べる）」
という指摘は実装方針としてそのまま使える。雑魚戦のテンポを上げる道具として入れる。

消耗品は作戦とは別に**使用許可**を持たせる。既定は「使わない」とし、許可しても
自動で使うのは蘇生・瀕死回復・守備重視時の状態回復だけに絞る。攻撃道具、加速薬、
MP 回復まで自動で切ると、ダンジョン全体で有限資源を配る判断をオートが奪うため。

### 2.8 盗むは期待値で設計する

FF6 の盗むは **コモン枠とレア枠**を持ち、成功率はレベル差で決まる。
「戦闘が 1 手番伸びるリスク」に見合う期待値が無ければ、誰も選ばない。
この作品では戦利品がラン終了時に消えるため、恒久報酬より大胆に配ってよい。
初回は必ずレア品・コモン品・まとまったゴールドのどれかを得る。
代わりに **1 体から取れるのは 1 回だけ**とし、成功まで同じ相手へ連打する作業をなくす。

宝箱も同じ考え方で、ゴールドだけの箱を廃止する。
**必ずゴールド + 装備または物資束**とし、深層ほど直近で解禁された品を優先する。
安価な回復品は複数個、希少品は 1 個にして、「量か質のどちらかが派手」な状態を保つ。

## 3. この作品への適用（決めたこと）

1. **属性は 4 つ**（炎・氷・雷・闇）。倍率は 2.0 / 1.0 / 0.5 / 0.0 の 4 段階
2. **状態異常は行動順に効くものを優先**（ねむり・どんそく・どく・かそく）
3. **範囲攻撃は減衰あり**（グループ: 2 体以下で増、全体: 3 体以下で増）
4. **敵の次の行動を行動順バーに出す**
5. **装備はラン内資源**（ゴールドと同じ。持ち帰れない）
   - 恒久強化が能力値に触れないという不変条件を守るため
6. **盗むは 1 体 1 回、初回は必ず報酬**（レア / コモン / ゴールド）
7. **自動戦闘は作戦 3 種**。消耗品は独立した許可制で、既定は使わない
8. **数値は必ず `tests/balance.gd` で測ってから確定する**
9. **宝箱は必ずゴールド + 装備または物資束**
10. **戦具は1個だけ持ち込み可能**。回復は1戦1回、無制限攻撃は通常攻撃未満
11. **戦闘中に使える装備は「どうぐ」欄へ統合**し、装備中の本人だけが使う

### 数値の決め方（挟み込み）

敵を 15 体足したときの実測。**攻撃力 1 点で結果が倍近く振れる**ので、
1 回測って「だいたい合っている」で止めてはいけない。

| 手 | 主に挑めた | 主を倒した |
|---|---|---|
| 足した直後（目安より強い） | 3% | 1% |
| 下げた | 15% | 6% |
| 下げすぎた | 43% | 23% |
| 中間 | 19% | 9% |
| 中の階だけ下げ、深い階は戻す | **36%** | **22%** |

ダメージが `攻撃力 - 守備/2` なので、攻撃力 1 点の差がそのまま通るダメージの
比率を大きく動かす。上下から挟み込んで決めるのが速い。

### 崩してはいけない前提

- 乱数は `DetRng` のみ。属性判定・状態異常・盗みの成否も**すべて決定的**であること
- 同時刻の行動順は id 昇順で確定
- LLM はテキスト層のみ

## 4. 固有名詞について

**他社作品の固有名詞を使わない。** 初版で呪文名に DQ の名前（ホイミ・メラ・ピオラ 等）を
そのまま置いてしまった。呪文体系は「共通の語幹 + 段階の接尾」という**構造**を借りるのはよいが、
語そのものは独自に作る。

この作品の体系は次のとおり。

| 系統 | 語幹 | 初級 → 中級 → 上級 |
|---|---|---|
| 火 | ヴァル | ヴァル / ヴァルガ / ヴァルギオ |
| 氷 | シラ | シラ / シラガ / シラギオ |
| 雷 | ゼル | ゼル / ゼルガ / ゼルギオ |
| 闇 | ノクス | ノクス / ノクスガ |
| 回復 | リアン | リアン / リアンガ（全体） |
| 補助 | — | ハステ（加速） / スロウ（鈍足） / スリープ（眠り） |
