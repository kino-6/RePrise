# ワールドローグライク向け候補アセット

更新された `docs/world_design.md` と `docs/quest_design.md` を基準に、地下 10 階の
潜行では不足するものだけを追加した。今回は候補の生成までで、`assets/` と
`tools/gen_assets.py` には取り込んでいない。

## 生成物

| 用途 | 候補 | 寸法・並び |
|---|---|---|
| ワールド | `candidate_tiles_world.png` | 208x16、16x16 x 13 |
| 町内装 | `candidate_tiles_town.png` | 144x16、16x16 x 9 |
| 町人 | `candidate_npc_townsfolk.png` | 144x32、24x32 x 6 |
| 三つの封 | `candidate_quest_seals.png` | 48x16、16x16 x 3 |

個別ファイルも置いた。

- 町人: `innkeeper` / `merchant` / `elder` / `scout` / `guard` / `villager`
- 封: `verdant` / `storm` / `ember_crown`

町人は町の中で立って会話する用途を優先した静止スプライト。歩かせる場合は、
採用後に 72x128 の歩行シートへ展開する。

## 規格検算

取り込み候補はすべて以下を通した。

- BGR555
- ファイルごとに可視色 15 色以内
- アルファは 0 / 255 のみ
- ワールド 208x16、町 144x16、町人 24x32、封 16x16

`candidate_world_concept_contact.png` はワールドと町を実寸で組んだ目視用。
`*_preview.png` は最近傍拡大、`*_source.png` は Imagegen の未縮小原画。

## Imagegen の最終プロンプト要件

組み込み Imagegen を使い、次の 4 枚を別々に生成した。

### ワールド

後期 16-bit JRPG の俯瞰ワールドタイル。4x4 の厳密な格子、マゼンタの溝、
末尾 3 セルは空。順番は海、草原、森、丘、山、門、町、洞、城、雪原、砂漠、
湿地、溶岩。文字・人物・UI は無し。通行可能地は暖色、通行不能地は寒色。
16x16 に縮小しても拠点地の大きなシルエットと 2〜3 個の特徴が残ること。

### 町内装

後期 16-bit JRPG の俯瞰町内装。3x3 の厳密な格子、マゼンタの溝。順番は木床、
石床、木組み壁、壁上端、出入口、店カウンター、ベッド、卓と椅子、絨毯。
蜂蜜色の木、クリーム色の漆喰、えんじの布、暗い青灰の輪郭、真鍮の差し色。
文字・人物・UI は無し。

### 町人

後期 16-bit JRPG の町人。3x2 の厳密な格子、マゼンタ背景。順番は宿主、行商人、
長老、斥候、衛兵、村人。全身・正面・同じ足位置。大きな頭と小さな体、
口は描かず、役割を色替えではなく被り物・外套・盾・前掛けなどのシルエットで
区別すること。

### 三つの封

後期 16-bit JRPG の封印遺物。横 3 セル、マゼンタ背景。左は苔むした青銅の
根の円環と緑の核、中央は銀の稲妻菱形と水色の結晶、右は黒赤の茨の冠錠と
赤い核。文字・UI は無し。16x16 で円・菱形・冠が区別できること。
