# サブクエスト・任意イベント64型

## 目的

このカタログは、AIにイベントそのものを発明させず、ゲーム側が用意した面白い
判断へ世界ごとの外見だけを与えるためのもの。

- ゲームが決める: 発生条件、選択肢、コスト、危険、報酬、危険度帯
- `DetRng` が決める: 世界へ置く型、AI不使用時の題名・関係者・原因・情景
- AIが変えてよい: `title`、`actor`、`cause`、`flavor` の四項目
- AIが変えてはいけない: event ID、選択肢、正解、戦闘、消費、報酬、確率

原本は [world_events.json](../data/world_events.json)、読込・抽選・検算は
[world_event_catalog.gd](../src/quest/world_event_catalog.gd) にある。

## 生成単位

標準では一つの世界へ次の三件を置く。

1. 街道イベント一件
2. 町イベント一件
3. 洞イベント一件

帝国や魔獣勢力を強く見せる世界では、勢力イベントを四件目として加える。
同じシード・同じ世界条件なら同じ型と代替文になる。全64型は四つの表示枠に
各三候補を持つため、AIを使わなくても一型あたり最低 `3^4 = 81` 通り、
カタログ全体では最低5,184通りの表層を持つ。

## 一件の構造

```text
event
├─ id / category / site_kind / danger / tags
├─ premise / trigger
├─ choices[2..3]
│  ├─ id / label
│  ├─ costs      先に支払うもの
│  ├─ risks      不利な状態や戦闘
│  ├─ rewards    実行を終えた後の結果
│  └─ operation  場所と戦闘条件からゲーム側が決める実行工程
├─ skin
│  ├─ title[3+]
│  ├─ actor[3+]
│  ├─ cause[3+]
│  └─ flavor[3+]
└─ ai_slots      各表示枠の最大文字数
```

## 選択後の実行工程

選択肢は決定した時点では完了しない。代償と発火した危険だけを先に処理し、
`EventOperation` が次のいずれかを割り当てる。報酬と済印は工程の完了後にだけ渡す。

| 発生場所・条件 | 完了に必要な実プレイ |
|---|---|
| 戦闘を含む手 | 予約された通常戦／格上戦に勝つ。逃走時は現場で再挑戦できる |
| 街道・勢力の非戦闘手 | 現場から街道を3歩進む |
| 町の非戦闘手 | 町へ入り、住人に接触する |
| 洞の非戦闘手 | 洞へ入り、宝箱か次の階段を調べる |

同時に持てる実行中イベントは一件だけ。別の出来事を踏んでも上書きせず、
未着手のまま残す。実行中の工程は中断データへ保存し、再開後も報酬前の状態へ戻す。
この規則により、AIが表層文を差し替えても「選択して結果窓を閉じるだけ」には戻らない。

`none` も明示的な結果であり、「データがない」という意味ではない。ゲームへ
接続するときは、各トークンを一か所の解決表で実際の数値効果へ変換する。
JSONへHP量や金額を直接書かないことで、バランス調整と世界生成を分離する。

## AI入出力

### AIへ渡すもの

`facts_for_ai()` は次だけを返す。

```json
{
  "category": "road",
  "site_kind": "world",
  "premise": "陸路をつなぐ橋が壊れ、進み方を選ぶ。",
  "trigger": "enter_route",
  "danger_band": [1, 8],
  "biome": "grassland",
  "slots": [
    {"key": "title", "max_length": 12, "fallback": "崩れた渡橋"},
    {"key": "actor", "max_length": 8, "fallback": "橋守"},
    {"key": "cause", "max_length": 28, "fallback": "増水で橋杭が流された"},
    {"key": "flavor", "max_length": 34, "fallback": "荷車の轍が水際で消えている。"}
  ]
}
```

`event_id`、選択肢、正解、コスト、危険、報酬は渡さない。AIには次の短い規約を
添え、JSON一個だけを返させる。

```text
四つのfallbackを、この世界に合う短い日本語へ言い換える。
事実や攻略法を追加しない。数字、英字、既存作品の固有語を使わない。
指定されたkey以外を出力しない。
```

### AIから受け取るもの

```json
{
  "title": "雨裂きの橋",
  "actor": "橋番の娘",
  "cause": "山の雪解けが杭をさらった",
  "flavor": "濁流に古い荷札が回り続けている。"
}
```

`apply_ai_skin()` は四項目を別々に検査する。空欄、文字数超過、改行、数字、
英字、括弧状の記号、禁止語を含む項目だけを棄却し、その項目だけfallbackへ戻す。
余分な `choices` や `rewards` をAIが返しても無視する。

## 現在の接続と境界

マップ上の発生と基本効果まで接続済み。

1. `WorldGenerator` が街道・町・洞へ一件ずつ、専用の `DetRng` から型を置く。
2. 発生地点、選択肢、一度きりの完了状態は世界・セーブ側が保持する。
3. `EventView` が固定三択と支払・危険・見返りを表示する。
4. `EventEffects` が固定トークンを一か所で数値と状態へ変換する。
5. fallbackは同じシードから確定し、AI候補が無くても必ず表示できる。

地形変更、近道、主弱体、一時同行、宿と町の貸し借りを含む全トークンが
ラン状態へ接続済み。主戦前の準備は実際の `Battler`、道の変化は遭遇判定、
店の支援は在庫、地形変化は `WorldMap` と中断差分へ反映する。
効果ゼロの撤退手だけは `defer: true` とし、イベントを済みにせず再訪できる。

`tests/test_world_events.gd` は全192選択肢について、既知名ではなく実際の状態差か
戦闘予約があることを検査する。効果ゼロと未実装トークンの壊したfixtureも拒否する。
AIによる四つの表示項目の差し替えは実行時にも接続されているが、選択結果は
AI文ではなく固定トークンから解決する。

これによりAIの応答速度、接続失敗、文面の品質が、進行・報酬・リプレイの
決定性へ影響しない。
