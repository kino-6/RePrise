# 世界クエストのサンプル

以下は `QuestGenerator` の骨格に、`QuestNarrativeText` の代替文または AI の表示文を載せた例。
太字が攻略上の事実で、ここは Script が作る。地名・呼び名・余談だけが差し替わる。

## 1. 水鏡の世界 — 三つの封

地形: 草原 → 湿地 → 雪原  
主: 影負う番人

| 帯 | 目的 | Script の事実 | AI が足せるもの |
|---|---|---|---|
| 低 | 根環の封 | **低い地の洞にある** | 「水辺の木が夜ごと鳴る」 |
| 中 | 雷晶の封 | **中ほどの地の洞にある** | 「青い光を見た旅人がいる」 |
| 高 | 冠火の封 | **高い地の洞にある** | 「雪の下で鐘が響く」 |

3 つを解けば城が開く。順番は自由。低地から順に安全に回るか、
先に高地へ踏み込んで帰路で残りを取るかが判断になる。

AI が全部失敗した場合も「根環の封 / 雷晶の封 / 冠火の封」のまま成立する。

## 2. 灰雨の辺土 — 継がれる火

地形: 荒地 → 火山  
主: 錆びた巨躯

```
低地の洞「眠る火種」
        |
        +-- 町の炉「鎮めの炉」---- 安全だが遠回り
        |
        +-- 中地の洞「荒ぶる炉」-- 近いが強敵
                     |
               高地「空の灯台」
                     |
                    城
```

重要文は **「火は町で鎮めるか、洞で鍛えられる」**。
AI は「かつて空を照らした火だった」のような理由を足せるが、
どちらの道が安全か、何と戦うかは変更できない。

この型の判断は、今の消耗で強敵を抜けるか、歩数と遭遇を払って町へ戻るか。

## 3. 風紋の環 — 二つの盟約

地形: 森林 / 砂漠 / 雪原  
主: 冠なき王

| 守り | 洞 | 結ばずに残した場合 |
|---|---|---|
| 苔の守り | 低地 | 主に毒の力が残る |
| 嵐の守り | 中地 | 主に速さが残る |
| 鋼の守り | 高地 | 主に硬い守りが残る |

三つのうち二つで入城できる。

- 状態回復が充実している → 苔を残して最短を取る
- 素早い編成 → 嵐を残して行動順勝負にする
- 魔法中心 → 鋼を残し、物理防御を無視する
- 万全を期す → 三つとも回るが、時間と消耗を払う

対応する効果 ID と数値は Script が固定する。AI は守りの名と由来しか触れない。

## 4. 薄明の島 — まことの遺物

候補:

1. 低地の「苔の遺物」
2. 中地の「月の遺物」
3. 高地の「灰の遺物」

この世界の正解は「月の遺物」。正解は `DetRng` が世界生成時に確定する。

町の証言:

- **「苔の遺物は まことの遺物ではない」**
- **「灰の遺物は まことの遺物ではない」**

この太字部分は Script が目的 ID から組む。AI が書けるのは、
「古い道標にも同じ印がある」のような後半の余談だけ。

プレイヤーは町を二つ回って正解だけを取りに行ってもよいし、
聞き込みを無視して近い洞から総当たりしてもよい。

## 5. 同じ骨格でも別世界になる例

`three_seals` の機械的な構造が同じでも、表示層は次のように変えられる。

| 世界 | 目的名 | 理由の方向 |
|---|---|---|
| 星影の野 | 星屑の器 / 朝凪の器 / 夜冠の器 | 空から落ちた器を鎮める |
| 白樺の世界 | 根守り / 川守り / 峰守り | 三地方の境を結び直す |
| 遠雷の島 | 銅鐘 / 銀鐘 / 黒鐘 | 城を囲む三つの鐘を止める |

どれも構造は「低・中・高の洞を自由順で三つ」。AI の文章量を増やしても、
遊びが増えたことにはしない。遊びの差は 4 型の依存関係と選択から出す。

## 6. 壊れた AI 出力

入力候補:

```json
{
  "world_name": "灰雨の環",
  "quest_title": "<script>",
  "boss_name": "他作品の固有呪文を含む王",
  "objective_names": ["翠の輪", "翠の輪", "第3の印"],
  "gate": {"count": 0},
  "truth_node": "candidate_low"
}
```

処理:

- `world_name` だけ採用
- 記号・英字を含む題は代替文
- 禁止語を含む主名は代替文
- 重複名と数字入りの名は、その項目だけ代替文
- `gate` と `truth_node` は読まない

結果として文章は一部変わるが、正解・城の条件・敵の力は一切変わらない。

## 機械可読な型

各目的ノードは次の形。AI へは `kind / band / biome / place` だけを渡す。

```json
{
  "id": "pact_mid",
  "role": "objective",
  "kind": "defeat_guardian",
  "site_id": "cave:2",
  "band": "mid",
  "requires": [],
  "requires_any": [],
  "boss_aspect": "haste"
}
```

`id / site_id / requires / boss_aspect` はゲーム専用。AI の入力と出力から除外する。
