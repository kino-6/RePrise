# アップグレードと職業マスターの再設計案

## 現状の問題

- 7種のアップグレードは、開始ゴールド・薬草・品数・値引きなど受動的な数値が中心。
  買った直後に新しい操作や判断が増えず、効果も実プレイ中に気づきにくい。
- `手の記憶` は熟練獲得を最大45%早めるが、職業★4の報酬自体は技1つだけ。
  弱い到達点までの時間を短くしても、マスターした達成感は増えない。
- 習得技は転職後もすべて使えるため、職業を重ねるほどコマンドは増える一方で、
  「その職を極めた人だけの遊び方」は残らない。
- `命の綱` は2段階あるのに説明は「1ランに1度」のままで、段階差が伝わらない。

能力値の恒久加算は、レベルと装備を失うラン構造を壊すので採用しない。
代わりに、恒久成長で「選べる準備・情報・戦い方」を増やす。

## 7種のアップグレード案

| 現在 | 改善後の役割 | プレイヤーが増やせる判断 |
|---|---|---|
| 旅支度 | 出撃準備点を得て、ゴールド・回復品・帰還用品へ配分する | 今回の世界と編成に合わせて初期資源を選ぶ |
| 手の記憶 | 後述の「継承印」を基本1枠から最大2枠へ増やす | どのマスター職のルールを持ち込むか選ぶ |
| 商いの伝手 | 出撃前に店の重点カテゴリを指定し、最大段階では1度だけ再入荷できる | 武器・防具・道具のどれを確実に探すか選ぶ |
| 備え | 固定の薬草ではなく、複数の支給品セットから1つ選ぶ | 安全・速攻・状態対策のどれを取るか選ぶ |
| 封の言い伝え | 封の位置だけでなく、番人の系統・失敗時の代償を段階的に開示する | 情報を見て攻略順を変える |
| 命の綱 | 全滅時に使うか終了するかを選び、段階で帰還先と保持物を改善する | 貴重な保険を今切るか温存する |
| 商いの目 | 一律値引きではなく、店ごとに提示される2つの取引から1つを選ぶ | 値引き・下取り・取り置きのどれを使うか選ぶ |

`商いの伝手` は品揃え、`商いの目` は支払い方法と役割を分ける。
準備画面では増加値だけでなく「今回使える新しい選択」を表示する。

## 職業長期報酬「継承印」

職業★6で技に加えて、その職固有のルールを変える「継承印」を解放する。
出撃前に、出撃メンバーが解放済みの印からパーティ全体で1枠だけ選ぶ。
`手の記憶` の強化後も上限は2枠とし、全印の常時加算にはしない。
★6は構成が開く節目であり、職業マスターは★8とする。★7・8には戦況を変える
職業固有奥義を一つずつ置く。8段階の報酬構造、奥義30種、継承技の制限は
`docs/job_ability_progression_design.md` を参照する。

| 職業 | 継承印の案 |
|---|---|
| 戦士 | 1戦に1度、`ぼうぎょ` で受けた単体攻撃へ反撃権を得る |
| 僧侶 | 1戦に1度、回復と同時に優先度順で悪性状態を1つ解く |
| 魔法使い | 戦闘開始時、敵1グループの最も低い属性耐性を開示する |
| 盗賊 | 戦利品を増量せず、決定的に作った候補2つから1つを選べる |
| 聖騎士 | 1戦に1度、指定した味方への致死傷を肩代わりして1HPで耐える |
| 忍者 | 1戦に1度、予告された単体攻撃を見てから回避姿勢を選べる |
| 狩人 | 開戦時に獲物を指定し、その敵の残HP・戦利品・次行動を詳しく読む |
| 魔剣士 | 出撃時、習得済みの属性1つを通常攻撃へ付与する |
| 召喚士 | 倒した非ボス種を1ランに1体だけ記録し、次戦以降に一度呼び出す |
| 銃士 | 開戦時、貫通・妨害・煙幕の弾種から初弾の性質を選ぶ |
| 錬金術師 | 移動中、固定レシピで所持品2つを別の消耗品へ調合する |
| 賢者 | 1戦に1度、直前に味方が使った技を重いコストで再演する |
| 時術師 | 1戦に1度、行動表にいる味方2人の次手番を入れ替える |
| 魔獣使い | 獣系の敵を瀕死時になだめ、撃破とは異なる報酬で戦闘を終える |
| 遊び人 | 最初の `運まかせ` は決定的に引いた候補2つを見て1つ選ぶ |

名称は仮。表示語は実装時に `Terms` へ置く。効果候補の抽選、戦利品候補、
同時刻の行動順はすべて `DetRng` とID順だけで決める。

## 実装順と検証

1. まず継承印なしでも従来どおり遊べるデータ形式と、出撃前の選択画面を作る。
2. 情報系・移動系・戦闘系を各1種だけ実装し、操作量と強さを測ってから15職へ広げる。
3. 7種のアップグレードを一度に置換せず、出撃準備、店、封、全滅の順で接続する。
4. `end_run()` の持ち越し境界は動かさず、保存するのは解放済み印と選択枠だけにする。
5. D-2の実プレイ相当シミュレーター完成後、未強化・中盤・全強化を同じ500シードで比較する。

完了条件は、各購入、各継承印、各★7・8奥義が実行時の選択を最低1つ増やすこと、
同じシードと選択から同じ結果になること、平坦な恒久能力加算を持たないこと。
