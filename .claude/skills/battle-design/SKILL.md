# 戦闘まわりを触るときの判断基準

根拠は `docs/battle_design.md`（往年の JRPG の調査結果）。迷ったらそちらを開く。
ここは「作業のたびに必ず確認すること」だけを短く置く。

## 1. 固有名詞

**他社作品の固有名詞を使わない。** ホイミ・メラ・イオ・ピオラ・ボミオス・ザオラル・
ベホイミ・ケアル・ファイラ等はすべて禁止。体系（語幹 + 段階の接尾）を借りるのはよいが、
語は独自に作る。この作品の語幹は 火=ヴァル / 氷=シラ / 雷=ゼル / 闇=ノクス / 回復=リアン。

## 2. 技を足すときのチェック

新しい技は、次のどれかで既存の技と**役割が違って**いなければ入れない。
「強い通常攻撃」を増やしても選択肢は増えない。

- 対象が違う（単体 / グループ / 全体 / 味方）
- 属性が違う（敵の耐性で効き目が変わる）
- 行動コストが違う（速いが弱い / 遅いが強い）
- 時間に触る（加速・鈍足・眠り）
- 戦闘の外に効く（盗む・逃走補助）

## 3. 数値は測ってから決める

経験値曲線・敵の能力・階層補正・新技の威力を触ったら、必ず実測する。

```bash
godot --headless --script res://tests/balance.gd
```

現状の帯: 主に挑めた 32% / 主を倒した 16%（自動操縦なので人が操作したときの下限）。

## 4. 決定性を壊さない

- 乱数は `DetRng` のみ。属性判定・状態異常の成否・盗みの成否もすべて決定的に
- 同時刻の行動順は id 昇順で確定させる
- 追加した確率要素は `tests/test_core.gd` に「同じシードで同じ結果」の検査を足す

## 5. 範囲攻撃の減衰は必ず入れる

グループ攻撃は敵が 2 体以下、全体攻撃は 3 体以下のとき、少ないほど 1 体あたりが増える。
減衰が無いと範囲攻撃が常に最適になり、単体攻撃を選ぶ理由が消える。

## 6. UI の規約

- 漢字は 14px 以上（`PixelUI.SIZE_TEXT`）。12px は かな・数字専用
- 文字は左上基準で置く（`PixelUI.draw_text`）。窓の中は `PixelUI.content(rect)` を基準に
- 画面に出す言葉は `src/ui/terms.gd` に置く。View に直書きしない
